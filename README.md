# PlantGuard AI

Create a modern, responsive, production-quality AI-powered web application called "PlantGuard AI".

Theme:

Modern agriculture + artificial intelligence.

Color Palette:

Primary: #22c55e

Secondary: #15803d

Accent: #86efac

Background: White and very light green gradients

Cards: Glassmorphism with soft shadows

Animations: Smooth and professional

==================================================

PROJECT OVERVIEW

==================================================

PlantGuard AI is an AI-powered crop health assistant that helps farmers identify plant diseases, understand causes, receive treatment recommendations, and improve crop productivity.

The application should look like a startup-level SaaS product rather than a student project.

AI CHAT ASSISTANT

==================================================

Create an AI chat interface on the result page.

Features:

- User can ask questions about the detected disease.

- Chat remembers the current disease diagnosis.

- Questions can be typed or spoken.

- Responses are generated using Gemini AI.

Example:

Detected Disease:

Tomato Early Blight

User:

"How do I treat this?"

AI:

Provides treatment recommendations.

User:

"Can this spread to nearby plants?"

AI:

Explains disease spread and prevention.

User:

"What organic treatment can I use?"

AI:

Provides organic treatment options.

Chat should display:

- User messages

- AI messages

- Typing indicator

- Suggested follow-up questions
